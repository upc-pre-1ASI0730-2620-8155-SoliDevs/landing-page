# Soli-Devs — Landing Page

Landing Page del modelo de negocio digital.
Curso **1ASI0730 – Aplicaciones Web** — UPC, Ciclo 2026-20.

## Tech stack

- HTML5 + CSS3 + JavaScript (vanilla)
- Responsive Web Design (Mobile First)
- Material Design como lenguaje de diseño
- i18n: English (`en-US`, default) & Latin American Spanish (`es-419`)
- Accessibility: WAI-ARIA attributes

## Features

- Presentación del modelo de negocio y productos
- Call-to-actions por segmento objetivo → redirigen a la Web Application
- Sección About-the-Product y About-the-Team (videos embebidos)
- Términos y condiciones de servicio (footer)

## Getting started

```bash
# Clone the repository
git clone https://github.com/Soli-Devs/landing-page.git
cd landing-page

# Open in browser or serve locally
npx serve .        # or simply open index.html
```
